# Sanjana V - Personal Portfolio Website

A modern, responsive, high-performance portfolio website built for **Sanjana V**, Computer Science (Data Science) undergraduate at Adhichunchanagiri Institute of Technology.

---

## 🌟 Overview & Highlights

- **Aesthetic**: Modern professional dark mode with a calm, high-tech Data Science & AI visual identity.
- **Color Palette**: Midnight Deep Blue (`#070a12`, `#0c1220`), Electric Cyan (`#06b6d4`), Royal Blue (`#3b82f6`), and Accent Indigo/Violet.
- **Typography**: Clean, crisp pairing of **Inter** & **Plus Jakarta Sans** with **JetBrains Mono** for metrics and technical badges.
- **Interactivity**: Dynamic neural network / data particles canvas, animated typing roles, interactive skills category filter, custom HTML5 video player, in-page PDF viewers, and 1-click clipboard actions.

## 🚀 How to Run Locally

You can open the website directly in any web browser:
1. Double-click `index.html` in your file explorer, OR
2. Serve via a lightweight Python local server:
   ```bash
   python -m http.server 8000
   ```
   Then open `http://localhost:8000` in your web browser.
